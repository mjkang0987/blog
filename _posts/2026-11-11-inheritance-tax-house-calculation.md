배우자와 자녀가 함께 아파트를 상속받는다면 상속재산 10억 원까지는 상속세가 대체로 나오지 않습니다. 일괄공제 5억 원과 배우자공제 최소 5억 원이 함께 적용되기 때문입니다. 배우자 없이 자녀만 상속받더라도 부모와 10년 이상 한집에 산 무주택 자녀라면 동거주택 상속공제로 최대 6억 원을 더 뺄 수 있어 세금이 1억 원 넘게 줄기도 합니다. 🏠

**핵심 요약 (TL;DR)**

- 상속세 = (상속재산 − 채무·장례비 − 상속공제) × 10~50% 누진세율이고, 기한 안에 신고하면 산출세액의 3%를 깎아 줍니다.
- 주택 상속에서 가장 큰 공제는 일괄공제 5억 원, 배우자공제(최소 5억~최대 30억 원), 동거주택 상속공제(최대 6억 원) 세 가지입니다.
- 신고·납부 기한은 사망일이 속한 달의 말일부터 6개월입니다. 2026년 11월 현재 공제 금액과 세율은 그대로입니다.

## 상속세 계산 순서 한눈에 보기 🧮

상속세는 받은 사람별로 따로 매기는 세금이 아닙니다. 돌아가신 분이 남긴 재산 전체에 세금을 한 번 매긴 뒤 상속인들이 받은 비율대로 나눠 내는 유산세 방식입니다. 계산은 다섯 단계를 거칩니다.

| 단계 | 계산 내용 | 주택 상속에서 확인할 점 |
|---|---|---|
| 1. 상속재산가액 | 부동산·예금·주식 등 전체 재산 평가액 | 아파트는 시가(매매사례가액 등)가 원칙 |
| 2. 상속세 과세가액 | 상속재산 − 채무 − 장례비 − 공과금 + 사전증여재산 | 주택담보대출 잔액은 채무로 차감 |
| 3. 과세표준 | 과세가액 − 상속공제 | 일괄·배우자·금융재산·동거주택공제 |
| 4. 산출세액 | 과세표준 × 세율 − 누진공제액 | 10~50% 5단계 누진세율 |
| 5. 납부세액 | 산출세액 − 신고세액공제 3% 등 | 6개월 안에 신고해야 3% 공제 |

사망 전 10년 안에 상속인에게 증여한 재산(상속인이 아닌 사람에게 준 재산은 5년)은 상속재산에 다시 더합니다. 미리 증여해 두었다고 해서 상속세 계산에서 빠지지는 않습니다.

## 상속세율과 누진공제액 📊

상속세율은 상속세 및 증여세법 제26조에 정해져 있습니다. 과세표준 구간이 다섯 개이고 최고세율은 50%입니다. 누진공제액을 쓰면 '과세표준 × 세율 − 누진공제액' 한 줄로 산출세액이 나옵니다.

| 과세표준 | 세율 | 누진공제액 |
|---|---|---|
| 1억 원 이하 | 10% | 없음 |
| 1억 원 초과~5억 원 이하 | 20% | 1,000만 원 |
| 5억 원 초과~10억 원 이하 | 30% | 6,000만 원 |
| 10억 원 초과~30억 원 이하 | 40% | 1억 6,000만 원 |
| 30억 원 초과 | 50% | 4억 6,000만 원 |

예를 들어 과세표준이 3억 원이면 3억 × 20% − 1,000만 원 = 5,000만 원이 산출세액입니다. 자녀를 건너뛰고 손자녀가 상속받으면 세액의 30%(미성년자가 20억 원을 넘게 받으면 40%)가 더 붙습니다.

## 일괄공제 5억 원과 배우자공제 ✅

**일괄공제**는 기초공제 2억 원에 자녀공제(1인당 5,000만 원)·미성년자공제·연로자공제 같은 인적공제를 더한 금액과 5억 원 중 큰 쪽을 고르는 제도입니다. 자녀가 두세 명인 보통 가정은 기초공제와 인적공제를 다 합쳐도 5억 원에 못 미쳐서 대부분 일괄공제 5억 원을 받습니다.

**배우자공제**는 배우자가 살아 있으면 적용됩니다. 배우자가 한 푼도 받지 않아도 최소 5억 원은 공제됩니다. 실제로 받은 금액이 그보다 많으면 아래 두 한도 안에서 받은 만큼 공제합니다.

| 구분 | 기준 |
|---|---|
| 최소 공제액 | 5억 원 (배우자가 받은 금액과 무관) |
| 한도 ① | 배우자 법정상속분 상당액 − 배우자가 사전증여받은 재산의 과세표준 |
| 한도 ② | 30억 원 |
| 5억 원 초과 공제 조건 | 상속세 신고기한 다음 날부터 9개월 안에 배우자 몫을 분할(등기 등)해 신고 |

배우자 법정상속분은 자녀 1명당 1, 배우자 1.5의 비율로 나눕니다. 자녀가 둘이면 배우자 몫은 1.5 ÷ 3.5, 즉 약 42.9%입니다. "상속재산 10억 원까지는 상속세가 없다"는 말은 배우자공제 5억 원과 일괄공제 5억 원을 합친 데서 나왔습니다.

## 금융재산 상속공제와 동거주택 상속공제 🏡

**금융재산 상속공제**는 예금·적금·주식 같은 금융재산에서 금융채무를 뺀 순금융재산에 붙는 공제입니다.

| 순금융재산 | 공제액 |
|---|---|
| 2,000만 원 이하 | 전액 |
| 2,000만 원 초과~1억 원 이하 | 2,000만 원 |
| 1억 원 초과 | 순금융재산의 20% (최대 2억 원) |

**동거주택 상속공제**는 집 한 채를 물려받는 자녀에게 가장 효과가 큰 공제입니다. 상속주택 가액(주택에 딸린 토지 포함, 해당 주택 담보채무는 차감)의 100%를 최대 6억 원까지 공제합니다. 상속세 및 증여세법 제23조의2가 정한 요건 세 가지를 모두 갖춰야 합니다.

| 요건 | 내용 |
|---|---|
| 10년 동거 | 돌아가신 분과 직계비속 상속인이 사망일까지 10년 이상 계속 한집에 거주(상속인이 미성년자였던 기간은 제외) |
| 1세대 1주택 | 그 10년 동안 계속 1세대를 이뤄 1세대 1주택에 해당(무주택 기간 일부는 인정) |
| 무주택 상속인 | 사망일 현재 상속인이 무주택자이거나 돌아가신 분과 공동으로 그 집 1채만 보유, 그리고 그 상속인이 주택을 상속 |

주민등록상 주소가 같다는 것만으로는 인정되지 않습니다. 과세 당국은 실제로 함께 살았는지를 생활 자료로 확인하므로, 따로 살면서 주소만 옮겨 둔 경우에는 공제가 거부될 수 있습니다.

모든 상속공제를 합친 금액은 상속세 과세가액을 넘을 수 없습니다. 상속인이 아닌 사람에게 유증한 재산이나 사전증여재산이 있으면 공제 한도도 그만큼 줄어듭니다.

## 사례로 보는 아파트 상속세 계산 💰

아래 계산은 모두 기한 내 신고(3% 공제)를 했고 사전증여는 없다고 가정했습니다. 배우자는 법정상속분만큼 실제로 상속받는다고 봤습니다.

| 구분 | 사례 A | 사례 B | 사례 C |
|---|---|---|---|
| 상속인 | 배우자 + 자녀 2명 | 자녀 2명 (동거 요건 충족) | 자녀 2명 (동거 요건 미충족) |
| 아파트 시가 | 15억 원 | 12억 원 | 12억 원 |
| 금융재산 | 2억 원 | 5,000만 원 | 5,000만 원 |
| 채무·장례비 | 1억 원 | 1,000만 원 | 1,000만 원 |
| 과세가액 | 16억 원 | 12억 4,000만 원 | 12억 4,000만 원 |
| 일괄공제 | 5억 원 | 5억 원 | 5억 원 |
| 배우자공제 | 약 6억 8,571만 원 | 없음 | 없음 |
| 금융재산공제 | 4,000만 원 | 2,000만 원 | 2,000만 원 |
| 동거주택공제 | 없음 | 6억 원 | 없음 |
| 과세표준 | 약 3억 7,429만 원 | 1억 2,000만 원 | 7억 2,000만 원 |
| 산출세액 | 약 6,486만 원 | 1,400만 원 | 1억 5,600만 원 |
| 납부세액(3% 공제 후) | 약 6,291만 원 | 1,358만 원 | 1억 5,132만 원 |

사례 A에서 배우자 법정상속분은 16억 원 × 1.5/3.5 = 약 6억 8,571만 원입니다. 최소 5억 원보다 크므로 이 금액이 공제됩니다. 사례 B와 C는 조건이 같고 동거주택 요건만 다른데, 납부세액 차이가 1억 3,774만 원에 이릅니다. 집 한 채가 재산의 대부분이라면 10년 동거 요건을 갖췄는지부터 따져 봐야 하는 이유입니다.

        for (var i = 0; i < t.length; i++) { if (b <= t[i][0]) { return Math.max(0, b * t[i][1] - t[i][2]); } }
        return 0;
      }
      function finDed(f) { return f <= 20000000 ? f : (f <= 100000000 ? 20000000 : Math.min(f * 0.2, 200000000)); }
      function calc() {
        var kids = Math.max(1, Math.round(num('ih-kids') / 10000));
        var gross = Math.max(0, num('ih-total') - num('ih-debt'));
        var mode = document.getElementById('ih-spouse').value;
        var sp = 0;
        if (mode === 'legal') { sp = Math.max(500000000, Math.min(gross * 1.5 / (1.5 + kids), 3000000000)); }
        if (mode === 'min') { sp = 500000000; }
        var fin = finDed(Math.min(num('ih-fin'), num('ih-total')));
        var house = Math.min(num('ih-house'), 600000000);
        var ded = Math.min(500000000 + sp + fin + house, gross);
        var base = gross - ded;
        var tax = rateTax(base);
        var credit = document.getElementById('ih-filed').checked ? tax * 0.03 : 0;
        document.getElementById('ih-rows').innerHTML = row('상속세 과세가액', won(gross)) + row('일괄공제', won(500000000)) + row('배우자공제', won(sp)) + row('금융재산 상속공제', won(fin)) + row('동거주택 상속공제', won(house)) + row('공제 합계 (과세가액 한도)', won(ded)) + row('과세표준', won(base)) + row('산출세액', won(tax)) + row('신고세액공제 (3%)', won(credit));
        document.getElementById('ih-result').textContent = won(tax - credit);
      }
      var ids = ['ih-total', 'ih-fin', 'ih-debt', 'ih-kids', 'ih-spouse', 'ih-house', 'ih-filed'];
      for (var i = 0; i < ids.length; i++) {
        document.getElementById(ids[i]).addEventListener('input', calc);
        document.getElementById(ids[i]).addEventListener('change', calc);
      }
      calc();
    })();
  </script>

## 신고 기한과 개편 논의 현황 📝

상속세는 사망일이 속한 달의 말일부터 6개월 안에 돌아가신 분의 주소지 관할 세무서에 신고하고 납부합니다. 4월 1일에 사망했다면 10월 31일까지입니다. 돌아가신 분이나 상속인이 외국에 주소를 두고 있으면 기한이 9개월로 늘어납니다. 기한을 넘기면 3% 신고세액공제를 받지 못하고 무신고·납부지연 가산세까지 붙습니다.

공제 금액을 올리자는 논의는 꾸준히 있었습니다. 2024년 정부가 낸 최고세율 40% 인하와 자녀공제 5억 원 상향안은 그해 12월 국회에서 부결됐습니다. 2025년 하반기에는 일괄공제를 8억 원으로, 배우자공제 최소액을 10억 원으로 올리는 안과 유산취득세 전환안이 함께 논의됐지만 여야가 접점을 찾지 못해 연내 처리가 무산됐습니다. 2026년 8월 정부가 발표한 세법개정안의 상속세 분야는 가업상속공제 개편(2027년 7월 1일 이후 상속분)이 중심이었고, 일괄공제·배우자공제 금액을 바꾸는 내용은 확인되지 않았습니다. 지금 상속이 일어나면 이 글에 정리한 현행 기준이 그대로 적용됩니다.

## 총평 📌

아파트 상속세는 계산식보다 공제를 얼마나 빠짐없이 챙기느냐에서 갈립니다. 배우자가 있으면 일괄공제와 배우자공제만으로 10억 원까지 세금이 거의 없습니다. 배우자 몫을 실제로 나눠 신고하면 공제는 더 커집니다. 배우자가 없다면 10년 동거 요건이 세금을 1억 원 넘게 좌우할 수 있습니다. 아파트를 시가로 평가하는지, 기준시가로 평가하는지에 따라 과세가액 자체가 달라지므로 매매사례가액과 감정평가 여부는 신고 전에 세무 전문가와 함께 확인하는 편이 안전합니다.

※ 본 글은 정보 제공 목적이며 투자 조언이 아닙니다. 개인별 상속세액은 홈택스나 세무 전문가를 통해 확인하시기 바랍니다.
