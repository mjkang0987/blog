부동산 계약을 앞두고 "복비가 얼마나 나오지?" 하고 걱정하는 분이 많지만, 답은 의외로 단순합니다. 중개보수는 **거래금액에 상한요율을 곱해** 계산하고, 구간별로 **한도액**이 정해져 있으면 그 금액을 넘지 못합니다. 요율표만 알면 내가 낼 수 있는 최대 금액을 직접 계산해 볼 수 있고, 이 금액은 어디까지나 **상한**이라 그 안에서 공인중개사와 협의할 여지도 있습니다. 🏠

**핵심 요약 (TL;DR)**

- 중개보수 = **거래금액 × 상한요율**, 단 구간별 **한도액**이 있으면 그 금액이 상한입니다.
- 주택 매매는 거래금액에 따라 **0.4~0.7%**, 임대차는 **0.3~0.6%**가 상한이며, 매매는 2억원 미만(25만·80만원), 임대차는 1억원 미만(20만·30만원) 구간에만 한도액이 붙습니다.
- 월세는 **보증금 + (월차임 × 100)**으로 거래금액을 환산하고, 그 값이 5천만원 미만이면 **월차임 × 70**으로 다시 계산합니다.
- 아래 계산기에 거래유형·금액을 넣으면 상한 중개보수가 바로 나옵니다. 협의 요율과 부가가치세(VAT)도 반영해 볼 수 있습니다.

## 중개보수는 어떻게 정해지나 — 요율 × 거래금액 💡

공인중개사에게 내는 중개보수, 흔히 '복비'라고 부르는 이 돈은 마음대로 정하는 값이 아닙니다. 「공인중개사법 시행규칙」과 시·도 조례가 정한 **상한요율** 안에서 결정됩니다. 계산의 뼈대는 하나입니다.

> **중개보수 = 거래금액 × 상한요율 (구간별 한도액이 있으면 그 금액을 넘지 못함)**

여기서 두 가지만 기억하면 됩니다. 하나는 거래금액이 커질수록 요율이 달라지는 **구간제**라는 것이고, 다른 하나는 금액이 작은 일부 구간에는 요율을 곱한 값과 상관없이 그 이상 받을 수 없는 **한도액**이 정해져 있다는 것입니다. 예컨대 요율을 곱해 30만원이 나오더라도 그 구간 한도액이 25만원이면 실제 상한은 25만원입니다.

상한요율은 말 그대로 '최대치'라서 실제로는 그보다 낮은 요율로 협의할 수 있습니다. 주택 요율은 시·도 조례로 정하므로 지역마다 다를 수 있지만, 대부분 같은 구조를 따릅니다. 아래 표는 서울특별시 조례 기준이며, 계약 전에는 해당 시·도 조례나 중개사무소에 게시된 요율표를 한 번 더 확인해 보는 편이 정확합니다.

## 주택 매매·교환 요율표 📊

주택(주택의 부속토지와 분양권 포함) 매매는 2021년 개정으로 거래금액 구간이 5단계에서 6단계로 세분화됐습니다. 특히 9억원 이상 고가 구간이 하나의 높은 요율(과거 0.9%)에서 세 단계로 나뉘었는데, 9억~12억원은 오히려 요율이 낮아진 반면 15억원 이상은 0.7%까지 올라갑니다.

| 거래금액 | 상한요율 | 한도액 |
|---|---|---|
| 5천만원 미만 | 0.6% | 25만원 |
| 5천만원 ~ 2억원 미만 | 0.5% | 80만원 |
| 2억원 ~ 9억원 미만 | 0.4% | 없음 |
| 9억원 ~ 12억원 미만 | 0.5% | 없음 |
| 12억원 ~ 15억원 미만 | 0.6% | 없음 |
| 15억원 이상 | 0.7% | 없음 |

매매는 2억원 미만 구간에서만 한도액이 있고, 그 이상에서는 요율만 곱하면 됩니다. 9억원·12억원·15억원 경계에서 요율이 한 단계씩 뛰기 때문에, 거래금액이 경계에 가까울수록 실제 부담이 크게 달라집니다.

## 주택 임대차(전세·월세) 요율표 📄

전세와 월세 같은 임대차 거래에는 매매보다 대체로 낮은 요율이 적용됩니다. 구간은 마찬가지로 6단계이고, 5천만원 미만과 1억원 미만 구간에만 한도액이 있습니다.

| 거래금액 | 상한요율 | 한도액 |
|---|---|---|
| 5천만원 미만 | 0.5% | 20만원 |
| 5천만원 ~ 1억원 미만 | 0.4% | 30만원 |
| 1억원 ~ 6억원 미만 | 0.3% | 없음 |
| 6억원 ~ 12억원 미만 | 0.4% | 없음 |
| 12억원 ~ 15억원 미만 | 0.5% | 없음 |
| 15억원 이상 | 0.6% | 없음 |

임대차는 1억~6억원 구간이 0.3%로 가장 낮고 넓게 잡혀 있어서, 서울 평균 전세가 수준의 거래는 대부분 이 구간에 들어갑니다. 전세보증금이 3억원이면 최대 90만원, 5억원이면 최대 150만원입니다.

## 월세는 거래금액을 환산해서 봅니다 🧮

전세는 전세보증금이 곧 거래금액이라 계산이 간단합니다. 까다로운 쪽은 월세입니다. 월세는 보증금과 매달 내는 월차임을 하나의 거래금액으로 합쳐야 하는데, 그 방법이 따로 정해져 있습니다.

> **거래금액 = 보증금 + (월차임 × 100)**
> 단, 이렇게 나온 금액이 **5천만원 미만**이면 → **보증금 + (월차임 × 70)**으로 다시 계산

배수를 낮추면 거래금액이 줄어 더 낮은 요율 구간이 적용되므로, 보증금이 적은 소액 월세 세입자의 부담을 덜어 주는 장치인 셈입니다.

| 계약 조건 | 환산 거래금액 | 적용 구간·요율 | 상한 중개보수 |
|---|---|---|---|
| 보증금 1억 / 월세 50만원 | 1억 + 5,000만 = 1억5,000만원 | 1억~6억(0.3%) | 45만원 |
| 보증금 5천만 / 월세 80만원 | 5,000만 + 8,000만 = 1억3,000만원 | 1억~6억(0.3%) | 39만원 |
| 보증금 3천만 / 월세 40만원 | 3,000만 + 4,000만 = 7,000만원 | 5천만~1억(0.4%) | 28만원 |
| 보증금 500만 / 월세 40만원 | 4,500만 < 5천만 → 500만 + 2,800만 = 3,300만원 | 5천만 미만(0.5%) | 16만5,000원 |
| 보증금 300만 / 월세 30만원 | 3,300만 < 5천만 → 300만 + 2,100만 = 2,400만원 | 5천만 미만(0.5%) | 12만원 |

아래 두 사례처럼 처음 계산한 값이 5천만원 미만이면 곱하는 배수가 70으로 낮아져 거래금액이 더 작아집니다. 두 경우 모두 요율을 곱한 값이 한도액 20만원 안이라 그대로 상한이 됩니다.

## 오피스텔·상가·토지는 체계가 다릅니다 🏢

주거용으로 쓰이는 일정 요건의 오피스텔이나 그 밖의 부동산은 요율 체계가 따로 있습니다.

| 구분 | 매매·교환 | 임대차 |
|---|---|---|
| 오피스텔 (전용 85㎡ 이하 + 전용 주방·화장실·목욕시설 구비) | 0.5% | 0.4% |
| 위 요건 밖 오피스텔 | 0.9% | 0.9% |
| 상가·토지 등 | 0.9% | 0.9% |

주거용 요건을 갖춘 오피스텔은 매매 0.5%, 임대차 0.4%의 고정 요율이 적용되고 한도액은 없습니다. 반대로 이 요건을 벗어난 오피스텔이나 상가·토지 등은 거래금액과 상관없이 **0.9% 이내**에서 협의로 정합니다. 요율이 최대 두 배 가까이 차이 나므로, 오피스텔은 계약 전에 전용면적과 설비 요건을 충족하는지 확인해 두는 것이 좋습니다.

        var out = (eok > 0 ? eok.toLocaleString('ko-KR') + '억' : '') + (man > 0 ? (eok > 0 ? ' ' : '') + man.toLocaleString('ko-KR') + '만' : '');
        return (out || '0') + '원';
      }

      // 주택 요율표 [상한(만원 단위, 미만), 요율(%), 한도액(원, 0=없음)]
      var houseSale = [
        [5000, 0.6, 250000],
        [20000, 0.5, 800000],
        [90000, 0.4, 0],
        [120000, 0.5, 0],
        [150000, 0.6, 0],
        [Infinity, 0.7, 0]
      ];
      var houseLease = [
        [5000, 0.5, 200000],
        [10000, 0.4, 300000],
        [60000, 0.3, 0],
        [120000, 0.4, 0],
        [150000, 0.5, 0],
        [Infinity, 0.6, 0]
      ];

      function pick(table, amountMan) {
        for (var i = 0; i < table.length; i++) {
          if (amountMan < table[i][0]) { return table[i]; }
        }
        return table[table.length - 1];
      }

      function calc() {
        var type = $('fee-type').value;
        var prop = $('fee-prop').value;
        var isSale = type === 'sale', isWolse = type === 'wolse';
        $('fee-price-box').hidden = isWolse;
        $('fee-deposit-box').hidden = !isWolse;
        $('fee-rent-box').hidden = !isWolse;
        $('fee-price-label').textContent = isSale ? '매매가 (만원)' : '전세보증금 (만원)';

        // 거래금액(만원) 산정
        var amountMan, hint = '';
        if (isWolse) {
          var deposit = num('fee-deposit'), rent = num('fee-rent');
          amountMan = deposit + rent * 100;
          if (rent > 0 && amountMan < 5000) {
            amountMan = deposit + rent * 70;
            hint = '환산액이 5천만원 미만 → 보증금 + (월차임 × 70)으로 재계산했습니다.';
          } else if (rent > 0) {
            hint = '거래금액 = 보증금 + (월차임 × 100)';
          }
        } else {
          amountMan = num('fee-price');
        }

        // 상한요율·한도액 결정
        var rate, cap = 0;
        if (prop === 'etc') {
          rate = 0.9;
        } else if (prop === 'offi') {
          rate = isSale ? 0.5 : 0.4;
        } else {
          var row = pick(isSale ? houseSale : houseLease, amountMan);
          rate = row[1]; cap = row[2];
        }

        // 협의 요율은 상한요율보다 낮을 때만 반영
        var effRate = rate, negoRaw = $('fee-nego').value;
        if (negoRaw !== '' && parseFloat(negoRaw) >= 0) {
          if (parseFloat(negoRaw) < rate) { effRate = parseFloat(negoRaw); }
          else { hint = (hint ? hint + ' ' : '') + '협의 요율이 상한요율 이상이라 상한요율을 적용했습니다.'; }
        }
        $('fee-hint').textContent = hint;

        var raw = amountMan * 10000 * effRate / 100;
        var capped = cap > 0 && raw > cap;
        var fee = capped ? cap : raw;
        var withVat = $('fee-vat').checked;
        var total = withVat ? fee * 1.1 : fee;

        var sub = [];
        if (capped) { sub.push('한도액이 적용됐습니다'); }
        if (withVat) { sub.push('중개보수 ' + won(fee) + ' + VAT ' + won(fee * 0.1)); }

        $('fee-amount').textContent = amountMan > 0 ? eokMan(amountMan) : '-';
        $('fee-rate').textContent = effRate + '%';
        $('fee-rate-sub').textContent = effRate < rate ? '협의 요율 (상한 ' + rate + '%)' : '상한요율';
        $('fee-cap').textContent = cap > 0 ? won(cap) : '없음';
        $('fee-result-label').textContent = (effRate < rate ? '협의 요율 기준 중개보수' : '상한 중개보수 (이 금액 이내에서 협의)') + (withVat ? ' · VAT 포함' : ' · VAT 별도');
        $('fee-result').textContent = amountMan > 0 ? won(total) : '-';
        $('fee-result-sub').textContent = amountMan > 0 ? sub.join(' · ') : '';
      }

      ['fee-type', 'fee-prop', 'fee-price', 'fee-deposit', 'fee-rent', 'fee-nego', 'fee-vat'].forEach(function (id) {
        $(id).addEventListener('input', calc);
        $(id).addEventListener('change', calc);
      });
      calc();
    })();
  </script>

## 실제로 이렇게 계산됩니다 ✍️

앞의 요율표를 실제 금액에 적용하면 다음과 같습니다. 모두 상한요율 기준 최대 금액이며, 부가가치세는 별도입니다.

| 거래 | 거래금액 | 구간·요율 | 상한 중개보수 |
|---|---|---|---|
| 아파트 매매 | 6억원 | 2억~9억(0.4%) | 240만원 |
| 아파트 매매 | 10억원 | 9억~12억(0.5%) | 500만원 |
| 아파트 매매 | 15억원 | 15억 이상(0.7%) | 1,050만원 |
| 전세 | 3억원 | 1억~6억(0.3%) | 90만원 |
| 전세 | 8억원 | 6억~12억(0.4%) | 320만원 |
| 상가 임대차 | 2억원 | 비주택(0.9%) | 180만원 |

같은 매매라도 6억원과 10억원 사이에서 중개보수가 240만원에서 500만원으로 두 배 넘게 뛰는데, 요율이 0.4%에서 0.5%로 오르는 동시에 거래금액 자체가 커지기 때문입니다. 6억원 아파트의 240만원에 중개사가 일반과세자라면 VAT 10%가 붙어 264만원까지 나올 수 있습니다.

## 계약 전에 확인하면 좋은 것들 🔎

요율표를 알더라도 실제 청구액을 보고 당황하지 않으려면 몇 가지를 미리 짚어 두는 편이 좋습니다. 먼저 표에 나온 금액은 모두 **상한**이므로, 그 안에서 낮춰 달라고 협의할 수 있고 고가 구간일수록 협의 여지가 큽니다. 여기에 **부가가치세**도 고려해야 합니다. 중개사무소가 일반과세자라면 보수에 10%가 별도로 붙고, 간이과세자라면 그보다 낮은 부가율이 적용됩니다. 사업자 유형은 사무소에 게시된 사업자등록증으로 확인하면 됩니다.

매도인과 매수인, 임대인과 임차인이 **각각** 중개사에게 보수를 내므로, 표의 금액은 '한쪽이 내는 상한'이라는 점도 기억해 두시기 바랍니다. 한 건물에 주택과 상가가 섞여 있으면 주택 면적이 전체의 2분의 1 이상일 때는 주택 요율을, 미만일 때는 주택 외 요율을 적용합니다. 분양권은 계약 당시까지 낸 금액(융자 포함)에 프리미엄을 더한 값을 거래금액으로 봅니다.

지급 시기는 중개인과의 약정에 따르되, 약정이 없으면 거래대금 지급이 완료된 날로 합니다. 계약을 앞두고 요율·금액·부가세 포함 여부를 미리 서면으로 확인해 두면 분쟁을 예방할 수 있습니다.

## 총평

중개보수는 복잡해 보이지만, 결국 **거래금액을 구하고 해당 구간의 요율을 곱한 뒤 한도액이 있으면 그 안으로 맞추는** 세 단계로 끝납니다. 월세라면 보증금과 월차임을 환산해 거래금액으로 바꾸는 과정만 하나 더해질 뿐입니다. 계약서에 도장을 찍기 전에 위 요율표와 계산기로 상한을 미리 확인해 두면, 청구된 금액이 정당한지 스스로 판단할 수 있고 협의의 근거도 마련됩니다. 정확한 요율은 거래하는 지역의 시·도 조례로 한 번 더 확인해 보시길 권합니다.
